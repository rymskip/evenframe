# fix(bump): repin the version the docs tell readers to depend on

- **Date:** 2026-11-22 23:15
- **Commit:** this commit
- **Area:** Tooling, docs

## Problem

After `pixi run bump minor` moved the crates to 0.7.0, the README and the website still told
readers to write `evenframe = { version = "0.6", … }`.

## Cause

The bump task repinned only manifests and lockfiles; nothing touched the documented requirement.

## Introduced

3861752 (2026-09-22, "0.5.2: drop macroforge_ts dependency, add bump task") added the bump task,
which repinned the crates and their dependents but not the docs.

## Fix

The bump task repins `evenframe = { version = "…" }` in every tracked Markdown file when the
documented `major.minor` requirement moves, leaving changesets, which record history, as they
were written.

## Verified

`pixi run verify` passed with the change (run `20261123T035543Z`); the bump task was not run, since
the crates are already at 0.7.0 and the docs were repinned by hand in the SurrealDB 4 commit.
